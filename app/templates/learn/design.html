Project Structure

task_management_system/
  config.py              # Dev / test / prod config
  run.py                 # Entry: create_app(), app.run()
  app/
    __init__.py          # create_app() factory
    config.py             # App-level config
    extensions.py         # db, migrate (avoid circular imports)
    forms.py              # Flask-WTF forms
    models/               # User, Task, Category
    routes/               # auth_bp, tasks_bp, categories_bp, web_bp, learn_bp
    services/             # auth_service
    templates/            # base.html, learn_base.html, learn/, app pages
    static/               # style.css, learn.css
    utils/                # decorators, error_handlers, validators
  data/                   # interview_preparation.json, assessment_questions.json
  tests/

Blueprints in This Project

  • learn_bp — Learning platform: intro, problem, design, Flask concepts, interview, assessment, revision. No URL prefix.
  • web_bp — Live app: login, register, dashboard, tasks, categories. Prefix /app.
  • auth_bp — API auth: register, login. Prefix /api/auth.
  • tasks_bp — API tasks: CRUD. Prefix /api/tasks.
  • categories_bp — API categories: CRUD. Prefix /api/categories.
