Flask: Configuration

App settings: secret key, database URL, env-based config. (Flask docs)

Application Factory

The factory is a function create_app(config_name) that creates and configures the Flask app. It lets you use different configs for development, testing, and production.

# config.py
class Config:
    SECRET_KEY = os.environ.get("SECRET_KEY") or "dev-secret"
    SQLALCHEMY_DATABASE_URI = os.environ.get("DATABASE_URL") or "sqlite:///task_management.db"

# app/__init__.py
def create_app(config_name="development"):
    app = Flask(__name__)
    app.config.from_object(config_by_name[config_name])
    db.init_app(app)
    # ... register blueprints
    return app

In This Project

  • config.py — Development, test, production config classes.
  • SECRET_KEY — For sessions and CSRF; set via env in production.
  • SQLALCHEMY_DATABASE_URI — SQLite for dev; PostgreSQL or other for prod.
