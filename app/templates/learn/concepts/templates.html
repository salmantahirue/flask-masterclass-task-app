What is Jinja2?

Jinja2 is Flask's template engine. You write HTML with {% raw %}{{ variable }}{% endraw %} for values and {% raw %}{% block content %}{% endraw %} for reusable layout. The server injects data and renders HTML.

{% raw %}<!-- base.html -->
<title>{% block title %}App{% endblock %}</title>
<body>
  {% block content %}{% endblock %}
</body>

<!-- dashboard.html -->
{% extends "base.html" %}
{% block content %}
  <h1>Welcome, {{ user.username }}</h1>
  <p>Tasks: {{ pending_count }} pending</p>
{% endblock %}{% endraw %}
