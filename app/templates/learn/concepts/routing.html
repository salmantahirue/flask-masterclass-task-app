Flask: Routing

Map URLs and HTTP methods to view functions. (Flask docs)

What is a Route?

A route maps a URL (and optional HTTP method) to a Python function. When a client requests that URL, Flask runs the function and returns its response (HTML, JSON, or redirect).

@web_bp.route("/login", methods=["GET", "POST"])
def login():
    if form.validate_on_submit():
        # ...
    return render_template("login.html", form=form)

@tasks_bp.route("/", methods=["GET"])
@token_required
def list_tasks():
    tasks = Task.query.filter_by(user_id=current_user.id).all()
    return jsonify([t.to_dict() for t in tasks])
