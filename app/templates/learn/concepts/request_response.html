Flask: Request & Response

Access request data; return HTML, JSON, or redirects. (Flask docs)

The request Object

The Flask request object holds the current HTTP request: URL, method, headers, and body. Use request.get_json() for JSON, request.args for query parameters, request.form for form data.

# JSON body (API)
data = request.get_json()
email = data.get("email")

# Query parameters: GET /api/tasks?status=pending
status = request.args.get("status")

# Form data (web UI)
form = LoginForm()
if form.validate_on_submit():
    email = form.email.data

Returning Responses

  • HTML: return render_template("dashboard.html", user=user)
  • JSON: return jsonify({"tasks": [...]}), 200 or jsonify({"error": "Not found"}), 404
  • Redirect: return redirect(url_for("web.dashboard"))
