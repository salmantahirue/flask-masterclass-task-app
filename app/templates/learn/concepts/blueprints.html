Flask: Blueprints

Modular sets of routes (and templates/static) registered on the app. (Flask docs)

What is a Blueprint?

A Blueprint is a set of routes (and optional templates/static) that you register on the app. It keeps code organized by feature instead of putting everything in one file.

# app/routes/web.py
web_bp = Blueprint("web", __name__)

@web_bp.route("/login", methods=["GET", "POST"])
def login():
    ...

# app/__init__.py
app.register_blueprint(learn_bp)   # no prefix -> /, /learn/...
app.register_blueprint(web_bp, url_prefix="/app")  # /app/login, /app/dashboard
app.register_blueprint(auth_bp, url_prefix="/api/auth")
app.register_blueprint(tasks_bp, url_prefix="/api/tasks")
app.register_blueprint(categories_bp, url_prefix="/api/categories")

In This Project

  • learn_bp — Learning platform (intro, problem, design, Flask concepts, interview, assessment, revision).
  • web_bp — Live app: login, register, dashboard, tasks, categories (prefix /app).
  • auth_bp — API auth: register, login (prefix /api/auth).
  • tasks_bp — API tasks CRUD (prefix /api/tasks).
  • categories_bp — API categories CRUD (prefix /api/categories).
