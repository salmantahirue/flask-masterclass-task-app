Flask: Forms (Flask-WTF)

Form classes with validation and CSRF protection. (Flask docs)

Why Flask-WTF?

Flask-WTF gives you form classes with validation (required, email, length) and built-in CSRF protection. You define a form class, pass it to the template, and call form.validate_on_submit() in the view.

# app/forms.py
class LoginForm(FlaskForm):
    email = StringField("Email", validators=[DataRequired(), Email()])
    password = PasswordField("Password", validators=[DataRequired()])

# In view
form = LoginForm()
if form.validate_on_submit():
    user, err = login_user(form.email.data, form.password.data)
    ...
return render_template("login.html", form=form)

In This Project

  • LoginForm — Email, password.
  • RegisterForm — Email, password, username.
  • TaskForm — Title, description, status, priority, due_date, category_id.
  • CategoryForm — Name.
  • CSRF token is included in forms automatically; validate with form.validate_on_submit().
