Flask Revision & Quick Reference

Quick summaries, key takeaways, and common mistakes to avoid.

Flask Concepts Summary

🛣️ Routing

What:
Map URL + HTTP method to a view function
How:
@bp.route("/path", methods=["GET", "POST"])
In Our Project:
/app/login, /api/tasks, /learn/flask, etc.

📄 Templates (Jinja2)

What:
HTML with variables and blocks for server-rendered pages
How:
render_template("page.html", var=value), {% raw %}{{ var }}{% endraw %}, {% raw %}{% block content %}{% endraw %}
In Our Project:
learn_base.html, base.html, dashboard.html, task forms

🧩 Blueprints

What:
Modular sets of routes (and templates/static) registered on the app
How:
Blueprint("name", __name__), app.register_blueprint(bp, url_prefix="/api/tasks")
In Our Project:
learn_bp, web_bp, auth_bp, tasks_bp, categories_bp

🗄️ Database (SQLAlchemy)

What:
ORM: Python models map to tables; relationships and queries
How:
Task.query.filter_by(user_id=id).all(), db.session.add(), db.session.commit()
In Our Project:
User, Task, Category models; Flask-Migrate for schema changes

Key Takeaways

  • Application factory: create_app(config_name) for dev/test/prod
  • Blueprints: Group routes by feature (auth, tasks, categories, web, learn)
  • Request/Response: request.get_json(), request.args; jsonify(), render_template(), redirect()
  • Forms: Flask-WTF for validation and CSRF; form.validate_on_submit()
  • Auth: Session for web UI; JWT for API; hash passwords (bcrypt)
  • Service layer: Business logic in services; routes only handle HTTP

Common Mistakes to Avoid

❌ One big app.py

Putting all routes in one file.

✅ Fix: Use Blueprints (auth_bp, tasks_bp, web_bp).

❌ Business logic in routes

Doing "check email exists", "hash password" inside the route.

✅ Fix: Move to a service layer (auth_service.register_user).

❌ Plain-text passwords

Storing passwords as-is in the database.

✅ Fix: Use bcrypt (or similar) to hash before saving.

❌ No ownership check

Returning any task by ID without checking user_id.

✅ Fix: Task.query.filter_by(id=id, user_id=current_user.id).first().

Interview Quick Tips

  • What is Flask? Lightweight WSGI web framework: routing, request/response, extensions.
  • What is a Blueprint? Modular set of routes (and optional templates/static) registered on the app.
  • GET vs POST? GET for reading (no side effects); POST for creating/submitting data.
  • What is the request object? Holds current HTTP request: URL, method, headers, body (get_json(), args, form).
  • Factory pattern? create_app(config_name) creates and configures the app for dev/test/prod.
  • JWT? Signed token encoding user identity; client sends in Authorization header; stateless for APIs.
